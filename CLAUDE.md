## Commands

- Single test file: `npx vitest run tests/camera-rig.test.js`
- Single test by name: `npx vitest run -t "partial test name"`
- Watch mode: `npx vitest`
- No linter or formatter is configured.
- Regenerate the desk kit GLBs: `/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/desk_kit.py` (append `-- --preview` to also render `tools/blender/preview.png` for a visual check).

## Big-picture flow

- `src/main.js` wires everything with top-level `await`: scene objects are created and registered with `interactions`, then `loadContent()` runs, overlay pages are registered under the same IDs as scene objects (`projects`, `gallery`, `blog`, `music`, `experience`), then the intro runs and mode becomes `idle`.
- Open/close sequence lives in `openItem()` / `closeItem()` in `main.js`: `setMode('zoomed')` → disable interactions → `rig.flyTo(CAMERA_ANCHORS[id])` → `overlays.open(id)` → pause render; closing reverses it (resume render before overlay fades). Camera anchors come from `src/scene/layout.js`.
- Lamp is the only interactable without an overlay: its click calls `lamp.toggle()`, which tweens `lampMood` through `setLampMood()` in `src/render/lighting.js`. `atmosphere.js` reads `getLampMood` and drives lightning via `applyWindowFlashLevel`.
- Scene modules load the generated GLB kit from `public/models/kit/` (`withFallback()` / `loadModel(url, { height: null })`), falling back to procedural `MeshStandardMaterial` geometry.
- Experience is special: on wide screens `openItem('experience')` enters board mode (`zoomed('experience')` with no overlay, render keeps running). A second `createInteractions` instance (`sheetInteractions`) makes the four featured sheets clickable; `src/ui/boardUi.js` shows the back pill, hint, and sheet card. `goBack()` unwinds timeline overlay → sheet card → board → desk, and is used by Escape and every back button. Narrow screens skip the board and open the timeline overlay directly. Spec: `docs/superpowers/specs/2026-10-06-investigation-board-design.md`.
- `src/ui/hud.js` is idle-only chrome (shown via `onModeChange`): its nav buttons call the same `openItem(id)` as 3D clicks, and `interactions.setHoverListener` feeds it the hovered object for the cursor tip.

## Tests

- Vitest runs in the default Node environment (no jsdom). Tests import real modules and stub globals (`document`, canvas contexts) and mock `gsap` with `vi.mock`/`vi.stubGlobal` — follow that pattern rather than adding a DOM environment dependency.

## Docs and style

- Design specs: `docs/design/` (realtime PBR doc is authoritative over the older baked-rendering doc) and `docs/superpowers/specs/`; implementation plans: `docs/superpowers/plans/`.
- Third-party assets in `public/` must be credited in `public/models/ATTRIBUTION.md`.
- Team code style (from `.cursor/rules`): minimal diffs, reuse existing helpers/deps before adding code, no unrequested abstractions or dependencies, fix bugs at the shared root cause. Mark deliberate shortcuts with a `ponytail:` comment naming the ceiling. Non-trivial logic leaves one small runnable check (a single test file).
- commit regularly with sensible small commits for a large feature
- When making a commit or a message on a github PR, don't co author any commits or write generated by claude code. keep it simple and clean
