# Ritvik Gupta — Portfolio

First-person 3D desk scene built with three.js + GSAP. Every object on the desk opens a section: laptop → projects, sketchbook → art gallery, journal → blog, vinyl → music, corkboard → experience. The lamp actually turns off.

## Commands

```bash
npm run dev       # dev server at http://localhost:5173
npm run build     # production build to dist/
npm run preview   # serve the production build
npm test          # content smoke tests (vitest)
```

## Replacing placeholder content

All content lives in `src/content/` — no code changes needed:

| File | Shape |
|---|---|
| `projects.json` | `{ id, title, description?, tech[], image?, repoUrl, liveUrl }` |
| `experience.json` | `{ id, title, org, start: "YYYY-MM", end: "YYYY-MM"\|"present", summary, body, tags[] }` — four most recent are pinned on the 3D board |
| `gallery.json` | `{ src, caption, type: "sketch"\|"photo" }` |
| `site.json` | name, Spotify `playlistId` + `profileUrl`, socials |
| `blog/*.md` | frontmatter `title:` + `date:` (YYYY-MM-DD), then markdown body |

Images: drop files into `public/` (e.g. `public/art/…`) and point the JSON `src`/`image` fields at them. Current placeholders are in `public/placeholders/`.

## Spotify now playing (vinyl label)

The record label shows the album art of whatever Ritvik is playing, else the cover of `site.json`'s `playlistId`. Live data comes from the Vercel function `api/now-playing.js` (visitors never log in); without it (e.g. `npm run dev`) the label shows the playlist cover.

One-time setup (full walkthrough and troubleshooting in `docs/spotify-setup.md`):
1. Create an app at https://developer.spotify.com/dashboard with redirect URI `http://127.0.0.1:8888/callback`.
2. `SPOTIFY_CLIENT_ID=… SPOTIFY_CLIENT_SECRET=… node tools/spotify/get-refresh-token.js`, open the printed URL, approve.
3. In Vercel project settings add env vars `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REFRESH_TOKEN`, then redeploy.

## Architecture

- `src/core/` — renderer/loop (`engine.js`), mode state machine (`state.js`), camera parallax + fly-to (`cameraRig.js`), raycast hover/click (`interactions.js`)
- `src/render/` — **realtime PBR lighting** (see `docs/design/2026-07-21-realtime-pbr-rendering.md`): window `DirectionalLight` + shadows, hemisphere fill, lamp `SpotLight`, GLB loader (`loadModel.js`), bloom composer; legacy bake helpers remain for transitional sprites
- `src/scene/` — one module per desk object + `layout.js` poses + `fillers.js` clutter; `MeshStandardMaterial` / screen shaders / soft-stylized GLB kit generated by `tools/blender/desk_kit.py` (see `docs/superpowers/specs/2026-10-05-soft-stylized-art-direction-design.md`)
- `src/ui/hud.js` — idle identity tag, section nav pill, and hover tooltip
- `src/ui/` — overlay manager, intro sequence, one module per content page
- Content pages are DOM overlays; 3D rendering pauses while one is open
- Lamp click tweens `lampMood` — warm lamp-dominant ↔ cool window-dominant

Design docs: `docs/design/` + `docs/superpowers/specs/`, plans: `docs/superpowers/plans/`.
