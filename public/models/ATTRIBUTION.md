## Desk kit (original — CC0)

`models/kit/*.glb` are generated by `tools/blender/desk_kit.py` for this project and released under CC0.
Regenerate with:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/desk_kit.py
```
